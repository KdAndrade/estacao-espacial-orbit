# 🚀 Missão: Estação Espacial Orbit

Este projeto simula sistemas de suporte de vida e operações da estação espacial.
O objetivo é garantir estabilidade e monitoramento contínuo dos módulos essenciais.

---

## 🌌 Camadas do Ambiente

- **develop** → Ambiente de desenvolvimento, usado para testes locais e experimentação.
- **stage** → Ambiente de homologação, onde são realizados testes de integração e validação antes da produção.
- **main** → Ambiente principal (produção), representando o sistema em operação real.
